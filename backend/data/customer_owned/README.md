# Customer-owned signals (legal path)

Drop JSON arrays here (or `{ "items": [ ... ] }`) exported by the brand/agency.

RadArt will ingest them on the next collection run.

Do **not** put scraped private Meta/TikTok dumps obtained by bypassing ToS.

Expected item fields: `title` (or `caption`/`text`), optional `platform`, `source`, `url`,
`published_at`, `engagement`.
